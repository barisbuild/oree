Everything you check,
already there.

Files, calendar, reminders, mail, music, weather, batteries and a timer. They read straight from your Mac, so nothing has to be open for them to be right.

Files

Still a desktop.
Go on, drag.

Click an icon, Command-click a few, or drag a rectangle across the lot. Oree keeps the reflexes you already have: drag to reorder, drop into a folder, drag out to another app.

  • Folders open in place, not in a window
  • Stacks by kind, search, rename, compress

Assistant

Ask the desktop.

Type what you need and an agent goes to work on this Mac. The answer opens over the desktop, picture and all, not in another window.

  • Works through Claude Code or Codex, on your own account
  • Asks before it changes a file or runs a command
  • Oree keeps no keys and has no account of its own

Picture

Any picture,
made of dots.

Choose any image. Oree prints it as a grid of dots and lets it dissolve into the desktop, so picture and widgets read as one surface. Until you choose, it follows your wallpaper.

Stays on your Mac

No account, no telemetry. The only thing that leaves is a location rounded to a kilometre, for the weather.

Asks once

macOS asks for calendar, reminders and location one time each. Full Disk Access is optional.

Easy to undo

One button in Settings gives the desktop back to Finder and puts everything as it was.

A few things to know.

Does it replace Finder?

No. Oree stands in for Finder's desktop, the layer behind your windows. Finder itself keeps running, your files stay where they are, and "Show in Finder" still opens Finder.

What does the assistant need?

Claude Code or Codex installed and signed in on your Mac. Oree drives the one you choose and holds no keys of its own. Without either, the widgets and files still work.

Can the assistant change my files?

Claude Code can, and it asks first: Oree shows you each request with Allow and Don't allow. Codex cannot ask, so Oree runs it read-only.

What does it cost?

Nothing. Oree is open source under the MIT licence. The agents use your own Claude or ChatGPT plan.

Which Macs does it run on?

macOS 14 or later. The glass surfaces need macOS 26; earlier versions get a frosted material instead.

How do I install it?

For now you build it from source with one command, ./run.sh. Xcode's command line tools are enough.
